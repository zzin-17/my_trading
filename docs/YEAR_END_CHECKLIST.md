# 연말 체크리스트 (KRX 휴장일)

**시기:** 매년 말(또는 익년 초), 한국 거래소 휴장일이 공지·갱신된 뒤 한 번만 진행하면 됩니다.

## 할 일

1. KRX(또는 거래소) 공지에서 **익년도 휴장일·임시 휴장**을 확인합니다.
2. 저장소에서 `src/data/krMarketHolidays.ts`를 엽니다.
3. 공지와 맞게 `YYYY-MM-DD` 목록을 추가·수정합니다.
4. `npm test` 또는 최소한 `npm run build`로 타입·빌드가 깨지지 않는지 확인합니다.
5. 변경 사항을 커밋합니다.

## 참고

- 이 목록은 영업일·차트 집계 등 **클라이언트 측 가정**에 쓰입니다. 공지 전에는 추정으로 넣지 말고, 확정된 날짜만 반영하는 것이 안전합니다.
